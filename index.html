Contributing through github

App Inventor 2

Created by Jose Dominguez / @josmasflores

Not familiar with github?

try.github.com

Fork the Repo

https://github.com/mit-cml/appinventor-sources

Use the "Fork" button on GitHub to create your own copy of the repository.

clone locally

git clone https://github.com/YOUR_USER_NAME/appinventor-sources.git

Clones your fork of the repository into the current directory. Swap YOUR_USER_NAME for your real GitHub username.

configure remotes

$ cd appinventor-sources
$ git remote add upstream https://github.com/mit-cml/appinventor-sources.git

.gitignore

$ cp sample-.gitignore .gitignore

If you don't do this, you will get in all kinds of trouble.

Checkout Dependencies

$ git submodule update --init

If you want to make changes to Blockly, make sure you follow the instructions in the main repository README file.

Create AuthKey

$ cd appinventor
$ ant MakeAuthKey

Check out the instructions in the main repository README file if you want to make your key persistent.

build app inventor 2

$ ant

run app inventor 2

$ google-cloud-SDK-folder/bin/java_dev_appserver.sh \
    --port=8888 --address=0.0.0.0 appengine/build/war/

You will need to download the Cloud SDK | App Engine for Java. These paths are relative to your AppEngine installation.

run the build server

$ cd appinventor/buildserver
$ ant RunLocalBuildServer

The build server is needed to create apk files.

you are now ready to go!

Navigate to localhost:8888

Check out the App Inventor Developer Overview for more information about the overall architecture of the system.
